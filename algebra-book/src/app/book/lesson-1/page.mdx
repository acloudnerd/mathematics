# Lesson 1: What is an Equation?

An equation is a mathematical statement that says two expressions are equal.

For example:

$x + 3 = 7$

This means:

> A number plus 3 gives 7.

The goal is to find the value of the unknown number.

In this case:

$x = 4$

because:

$4 + 3 = 7$
